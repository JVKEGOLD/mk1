# Goldware Landing Page

A premium, single-page marketing site concept focused on helping businesses grow through strategy, design, and performance.

## 🚀 Overview

This repository contains a polished front-end landing page with:

- Premium dark + gold visual theme
- Fixed top navigation
- Custom animated cursor interactions
- Gradient and grid visual overlays
- Responsive, full-viewport hero presentation

## 📁 Project Structure

- `test` — Main HTML document (currently includes embedded CSS and JavaScript).

## 🛠️ Getting Started

### Run locally

Because this is a static HTML page, you can open it directly in your browser:

1. Clone the repository.
2. Open `test` in a browser.

For better local behavior, serve with a lightweight static server:

```bash
python3 -m http.server 8080
```

Then visit: `http://localhost:8080`
